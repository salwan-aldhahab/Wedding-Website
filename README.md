## Introduction

The Wedding Website project aims to provide a seamless and elegant web experience for wedding events. The website includes details about the wedding, RSVP functionality, photo galleries, and more.

## Features

- Responsive design
- RSVP form
- Photo gallery
- Event schedule
- Contact form

## Technologies Used

- HTML
- CSS
- JavaScript

## Setup and Installation

To get started with the project, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/salwan-aldhahab/Wedding-Website.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Wedding-Website
    ```
3. Open `index.html` in your preferred web browser to view the website.

## Usage

- Customize the HTML, CSS, and JavaScript files to fit the specific needs of your wedding.
- Update the content in the HTML files to include your wedding details.
- Add your own images to the photo gallery.
